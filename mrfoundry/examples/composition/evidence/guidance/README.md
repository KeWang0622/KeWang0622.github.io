# What this walkthrough demonstrates

MRFoundry is a set of instructions and supporting references used by an existing coding agent. The agent reads relevant guidance, plans the task, writes configuration/glue code and runs scientific software. Installing the skills does not itself install every MRI application. The package provides tool-setup guidance, tool/data conventions, checks, original references and project-memory procedures.

The golden-angle example is a condensed, artifact-backed replay of a recorded Codex workflow. The displayed skill guidance is a current snapshot mapped to those steps; the original run did not preserve a complete skill-read transcript. This is not a measured comparison against an agent without MRFoundry. Researcher intervention prompted the quality revision.

Public artifacts contain source, sequence definitions, scalar reports and original synthetic validation evidence. BrainWeb-derived anatomical arrays and images are excluded. The MRI three-letter example is a separate playful static Fourier experiment, with limited sequence timing checks and unequal 1/20-shot durations.

The [instruction archive](instruction-snapshots.zip) contains the original skill files as provenance snapshots. Use the official repository for installation and linked supporting references: https://github.com/KeWang0622/MRFoundry
