# MRFoundry in practice

A ten-slide animated walkthrough showing how to use MRFoundry with a coding agent: request, relevant guidance, scientific tools, artifacts, researcher review and iteration.

Open index.html through a static HTTP server. Use arrow keys or navigation controls; P opens presenter notes. Each slide animates and then holds.

The recorded golden-angle workflow is mapped retrospectively to current instruction snapshots. See composition/evidence/README.md for original tools, sources, reports and scope. The three-letter MRI example is a separate playful Fourier experiment.

Runtime and font licenses are included in runtime/ and composition/assets/. MRFoundry instruction snapshots include their MIT license.
